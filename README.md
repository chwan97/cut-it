# cut-it 原 APP 功能文档

cut-it 是一款图片裁剪工具，用于在一张或多张本地图片上标注多个矩形区域，并将每个区域导出为独立图片。

本文根据原 APP 的界面与业务流程整理，保留其功能说明。当前仓库仅保存本文，不包含可运行的应用、代码或依赖。

## 核心流程

1. 选择一张图片，或选择包含图片的文件夹。
2. 在图片上拖拽绘制裁剪框，可为同一张图片添加多个框。
3. 调整每个裁剪框的位置和尺寸，逐张完成标注。
4. 点击“开始裁剪”，生成裁剪结果。
5. 在完成提示中打开结果所在文件夹。

## 图片导入

- 首页提供“选择一个文件夹开始裁剪”和“选择一张图片开始裁剪”两个入口。
- 使用系统文件选择窗口读取本地图片。
- 单张图片选择器筛选 JPG、PNG；文件夹导入识别 JPG、JPEG、PNG 及其大写扩展名。
- 文件夹导入读取当前目录中的图片，不递归读取子文件夹，并按文件名自然排序。
- 读取图片尺寸信息；没有找到图片或尺寸读取失败时，显示提示并阻止进入裁剪流程。
- 原 APP 的导入流程会将部分大写扩展名及 `.jpeg` 扩展名规范化为 `.png` 或 `.jpg`，涉及原文件重命名。

## 图片浏览

- 裁剪页面展示当前图片及“当前张数 / 总张数”。
- 支持使用上一张、下一张按钮及方向键切换图片。
- 到达第一张或最后一张时提供提示。
- 每张图片独立保存本次操作中的裁剪框；切换图片时取消当前框的选中状态。
- 窗口尺寸变化后，按相对位置和比例重新显示裁剪框。

## 裁剪框编辑

- 在图片空白区域按下并拖动鼠标，创建矩形裁剪框。
- 一张图片可以创建多个裁剪框，各框显示序号及预计输出的宽、高。
- 点击选中一个框，可拖动位置，通过边缘或角上的控制点调整尺寸，或点击删除按钮移除。
- 宽高可以独立调整，不强制保持固定比例。
- 框的移动和缩放受到图片边界限制；选中框显示在其他框的上层。
- 点击图片上的空白区域取消选中。
- 原 APP 以约 20 像素的输出宽、高作为小尺寸限制和提示依据，过小的区域不会正常创建或会显示尺寸警示。

## 裁剪与导出

- 点击“开始裁剪”后，检查所有导入图片是否都已标注裁剪框。
- 如有图片未标注，跳转到第一张未标注图片，提示用户补充后再开始。
- 根据各框在原图中的位置和比例计算裁剪区域；原逻辑包含对部分 EXIF 旋转方向的处理。
- 在源图片所在文件夹中创建带时间戳的结果目录：`cut-it-resultYYYY-MM-DD-HH-mm-ss`。
- 每个裁剪框生成一张独立图片，沿用源图片的扩展名，并在处理时保留图片元数据。
- 只有一个裁剪框时，输出使用原图片文件名；有多个框时，追加从 1 开始的序号，例如 `photo_1.jpg`、`photo_2.jpg`。
- 裁剪过程中显示“裁剪图片生成中...”及已处理图片数、总图片数，进度按源图片计数。
- 完成后显示“照片裁剪已完成”，用户可打开结果文件夹或关闭提示。

## 提示与退出

- 调用系统文件选择窗口时显示加载提示。
- 图片读取异常、未标注裁剪框等情况显示警告。
- 离开裁剪页面或关闭应用时需要确认；裁剪中的退出提示说明数据不会保存。
- 裁剪框是本次会话中的临时数据，没有项目保存、重新打开后恢复标注的功能。

## 原 APP 的辅助功能

- 显示由本机网络接口信息生成的机器码；获取失败时提示错误，并阻止开始裁剪。
- 点击机器码区域可打开日志文件，供排查问题。
- 同一时间只运行一个应用实例，再次启动时切换到已有窗口。
